# Playwright 활용 회원가입 테스트

### 🔹 개요

웹 애플리케이션의 회원가입 기능을 Playwright를 활용하여 자동화 테스트를 구현했다. 

사용자의 회원가입 과정에서 발생할 수 있는 다양한 입력 케이스를 검증하고,
정상적인 회원가입 흐름 및 예외 처리(유효성 검사)가 올바르게 동작하는지 확인하는 것을 목표로 하였다.

또한 테스트 코드의 유지보수성과 확장성을 고려하여
Page Object Model(POM) 구조와 데이터 기반 테스트 방식을 적용하였다.

---

### 🔹 목표

- 회원가입 기능의 정상 동작 여부를 자동으로 검증한다.
- 입력값 유효성 검사(Validation)가 올바르게 동작하는지 확인한다.
- 다양한 사용자 입력 케이스를 효율적으로 테스트한다.
- 반복 가능한 자동화 테스트 환경 구축한다. 
- Playwright 기반의 실무형 자동화 구조 설계 경험 확보한다.

---

### 🔹 자동화 시나리오 설계
대상: 웹 서비스 회원가입 페이지
1. 이메일 입력
2. 사용자명 입력
3. 비밀번호 입력
4. 비밀번호 확인 입력
5. 약관동의 체크
6. 회원가입 버튼 클릭
7. 유효성 검사 메시지 출력

---

### 🔹 테스트 범위

- 정상 회원가입
- 이메일 형식 검증
- 비밀번호 조건 검증 (길이, 특수문자 등)
- 비밀번호/비밀번호 확인 일치 여부
- 필수 입력값 누락 케이스
- 성공/실패 메시지 검증
